### 1. https://discuss.koinly.io/t/hyperliquid-missing-purchase-history-issue/26508
Question: seven outgoing transfers from a Hyperliquid wallet flagged as missing purchase history (10,626 USDC unmatched).
Reply:
> Had the same "missing purchase history" on Hyperliquid and it came from how the sync models perps: closes get treated as disposals of an asset you never bought, and perp↔spot moves look like withdrawals. What fixed it for me was replacing the synced wallet with a file import: every perp close as a realized gain/loss row, fees as cost, funding summed per day, deposits/withdrawals as plain transfers that match the Arbitrum side. I built a free exporter that writes that CSV from the public API in your browser (disclosure: mine): [link]. The mapping table is on the page if you'd rather build the file yourself. Compare the summary it prints with the wallet's PnL page before importing.
