# Chrome Web Store listing

**Name:** AI Chat Layer: folders, prompts, export

**Summary (132 chars max):** Folders, prompt library and Markdown export for ChatGPT, Claude and Gemini. Local only, no account.

**Description:**

Organize your AI chats the way you organize files.

FOLDERS
Save any ChatGPT, Claude or Gemini conversation into a folder and open it again from any of the three sites. One place for all your threads.

PROMPT LIBRARY
Save the prompts you reuse, search them, click to insert into the chat box. Use {{selection}} to drop in the text you have highlighted.

MARKDOWN EXPORT
Download or copy the whole conversation as clean Markdown: headings, lists, code blocks with the language, tables and links preserved. Paste into Notion, Obsidian, a wiki or a ticket.

PRIVATE BY DESIGN
Everything is stored in your browser. The extension makes no network requests except an optional license check. No account, no telemetry.

FREE AND PRO
Free: 3 folders, 10 prompts, unlimited exports. Pro: unlimited folders and prompts, one-time payment, one key for all your browsers.

Shortcut: Alt+A opens the panel.

**Category:** Productivity. **Language:** English.

**Permissions justification:** `storage` keeps folders and prompts in the browser. Host permissions for chatgpt.com, chat.openai.com, claude.ai and gemini.google.com are required to read the conversation on the page and add the panel. No remote code.

**Privacy policy (host it on the checkout domain or Pages):** AI Chat Layer stores folders, saved conversation links and prompts locally in your browser using chrome.storage. It does not collect, transmit or sell any data. The only network request is made when you enter a license key in the options page, to verify the key against our server; the request contains the key and nothing else.
