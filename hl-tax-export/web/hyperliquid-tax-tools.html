The events file

events.csv is one row per normalized event with venue, kind, time, asset, size, price, realized PnL, fee, cash amount, transaction hash and a plain-English note. Kinds: perp_open, perp_close, spot_buy, spot_sell, funding, deposit, withdraw, transfer_in, transfer_out, liquidation, pm_buy, pm_sell. Any tool with a custom CSV importer can be fed from it with a column mapping, and any spreadsheet can pivot it.

Reconciling before you trust an import

  1. Export the tax year and read summary.txt.
  2. Compare the per-asset realized PnL with Hyperliquid's portfolio page for the same period.
  3. Compare deposits and withdrawals with your Arbitrum wallet.
  4. Only then import into the tax tool, and compare its totals to the summary.

Most "my numbers are wrong" cases are a second wallet, a sub-account or a vault that was not exported. Export each address separately.
